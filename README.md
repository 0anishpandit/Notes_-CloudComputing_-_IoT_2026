# Cloud Computing & IoT 2026

This repository is a complete study resource for the Cloud Computing and IoT 2026 course. It is designed to organize all the weekly learning material in one place, making it easy to revise concepts, follow tutorials, and practice key questions.

## What this repo contains

The repository includes:

- Week-wise notes from Week 1 to Week 12
- Tutorial explanations and guided learning material
- Workshop lecture notes and class summaries
- Handwritten notes and quick revision points
- Practice questions and problem-solving exercises
- Course-focused learning content for Cloud Computing and IoT concepts

## Course focus

This course covers the fundamentals and practical applications of:

- Cloud Computing architecture and services
- Virtualization and distributed systems
- Internet of Things (IoT) concepts
- Sensors, devices, and connectivity
- Data collection and cloud integration
- Smart applications and real-world IoT use cases
- Practical implementation and study-based questions
